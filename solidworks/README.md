# מדריך SolidWorks שלב אחר שלב

אפליקציית ווב שבה כותבים מה רוצים לתכנן ב-SolidWorks (למשל "בורג M8×40 ראש משושה") ומקבלים מדריך מלא, שלב אחר שלב, מקובץ חדש ועד חלק מוגמר.

## תכונות
- ספריית 11 מדריכים מוכנים שעובדים בלי מפתח: בורג, אום, דסקית, גלגל שיניים, תושבת L, ציר וקפיץ, ולמיזוג ואוורור: מאיץ צנטריפוגלי, מאוורר צירי, מפוח עם בית ספירלי וסוללת קירור
- בקשה חופשית עם AI (אופציונלי, דורש מפתח Claude API)
- בחירת רמה (מתחיל / בינוני / מתקדם) ושפת ממשק (אנגלית / עברית)
- כרטיס לכל שלב: מסלול בתפריט, פעולות, טיפ ובדיקה
- סרגל התקדמות וקפיצה בין שלבים
- "נתקעת?": שאלה על השלב הנוכחי

## שימוש
1. פתחו את האתר (GitHub Pages).
2. בחרו מדריך מהספרייה. לבקשה חופשית: הזינו מפתח Claude API (מ-https://platform.claude.com/settings/keys). המפתח נשמר רק ב-localStorage בדפדפן שלכם ונשלח ישירות ל-Anthropic.
3. כתבו מה ליצור ולחצו "צור מדריך".

הקוד נמצא ב-`index.html`, והמדריכים המוכנים ב-`guides.js`. אין צורך בשרת או ב-build. כדי להוסיף מדריך, מוסיפים אובייקט למערך `LIBRARY`.
